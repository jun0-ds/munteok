# desk — fast + private

지금 작업하는 자리. 변화 빠르고, 비공개.

## 기대 거주

- `agenda/current.md` — 진행 중 의제 큐 (능동 surface 대상)
- `agenda/initiative-log.md` — instance가 먼저 시작한 기록 (능동성 관찰)
- `memory/` — 도메인·core·archive·secrets. 글로벌 메모리 본거지
- `notes/` — per-device inbox + shared
- `sonmat/` — scribe 로그 (`bridge-note.md`·`journal.md`) 거주
- `diary.md` — 짧은 관찰

## 원칙

- 자유 작성 — 모든 기기에서 부담 없이
- 정착하면 hearth로 승격, 일반화되면 bedrock으로
- 임시 파일은 정기 정리

## bridge-note와의 관계

`desk/sonmat/bridge-note.md`는 *직전→다음* 핸드오프 (post-work, scribe 자동).
`agenda/current.md`는 *진행 중 큐* (능동 surface 대상, 사람+instance 큐레이션).
bridge-note Carry Forward 항목 중 *지속될 것*은 agenda로 promote.
