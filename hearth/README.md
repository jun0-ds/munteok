# hearth — slow + private

이 instance의 *길든 자리*. 정체성·자세·누적 판단. 변화는 느리지만 *instance만의 것*.

비유: Aristotle의 techne, Bourdieu의 habitus — 체화된 양식.

## 기대 거주

- `identity/` — position, relations, voice (호칭·톤)
- `policy/` — @include atomic rules (sync, secrets, repo-setup 등)
- `heuristics/` — anti-patterns, 누적 판단
- `changelog/` — identity·policy 변천사 (왜 바뀌었는지)

## 원칙

- 변경은 신중하게 — *길든 것을 다시 길들임*
- 변경 시 changelog에 1-2줄 (날짜 + 이유)
- bedrock의 패턴을 *instance 방식으로* 구체화한 자리

## L4 (pathfinding) 거주지

policy + identity prior가 L4의 substrate. 시스템 prompt에 *주입*되는 자료가 여기 살음.
