# 문턱 작업공간

이 폴더는 사용자의 업무와 개인 작업을 모으는 작업공간이다. 보안 sandbox나 접근 권한 경계가 아니다.
작업 범위 밖의 자료는 필요와 사용자의 허용 범위를 확인한 뒤 읽는다.

## 시작과 라우팅

매 세션에 다음 최소 공통 문서를 순서대로 읽는다.

1. `.munteok/hearth/voice.md`
2. `.munteok/desk/memory/core/identity.md`와 `work-style.md`
3. 루트 `CONTEXT.md`

그 뒤 요청에 맞는 업무/개인 영역과 프로젝트·이슈의 `CONTEXT.md`로 이동해 필요한 자료만 읽는다.
루트에서 모든 회사 자료와 개인 자료를 전부 읽지 않는다. 도메인 지식은 해당 영역에 보관하고
다른 회사나 개인 작업에 섞지 않는다. `.munteok/desk/memory/MEMORY.md`는 공유 가능한 지식의 안내다.

그날 첫 작업에 다음 명령을 한 번 실행한다. 도구가 오늘 확인했다면 건너뛰며 확인 실패는 작업을 막지 않는다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File '<작업공간 절대경로>/.munteok/tools/Check-Updates.ps1' -WorkspaceRoot '<작업공간 절대경로>'
```

`<작업공간 절대경로>`는 실제 루트로 치환한다. 업데이트는 알림만 하며 자동 설치·pull·재시작하지 않는다.
Windows 밖에서 실행할 PowerShell이 없다면 확인을 생략하고 이 한계를 알린다.

## 새 작업과 파일

새 작업은 업무·개인 중 알맞은 영역에서 프로젝트 또는 이슈 폴더를 만들고 시작한다.
업무를 회사별로 나눌 때는 회사 폴더에 `CONTEXT.md`와 `보관/`을 두고 그 아래 작업을 만든다.
`.munteok/workitem-template.md`를 복사해 새 작업의 `CONTEXT.md`로 채운다.
자료·결과·임시 폴더는 그 작업 폴더 안에 필요할 때 만들고 루트에 산출물을 흩뿌리지 않는다.
지금 하는 일과 결과물 위치를 작업 `CONTEXT.md` 및 상위 활성 목록에 함께 반영한다.

## 완료와 보관

`.munteok/completion.md` 절차를 따른다. 완료한 작업은 같은 업무·회사·개인 영역의 `보관/YYYYMMDD_이름/`으로 옮긴다.
원본과 재작업·재현에 필요한 파일은 보존하고 자신이 만든 불필요한 임시 파일만 정리한다.
진행 중인 서비스나 프로젝트 전체를 완료 이슈와 함께 옮기지 않는다.
이동 전에 기록 경로와 이전 절대경로를 남기고 이동 뒤 활성 인덱스·상대 링크를 갱신한다.
평소에는 보관 본문을 읽지 않고 과거 작업 요청 때 찾아간다.

## 설치와 기존 설정

이 블록과 `.munteok/tools/`는 문턱 관리 영역이다. 다른 문서와 메모리는 사용자 자료다.
계정·권한·모델·전역 harness 설정을 설치 편의로 초기화하지 않는다.
손맛 규율은 가이드의 손맛 설치 단계로 연결해 기본 로드한다. 미설치라면 완료로 표시하지 말고
설치 안내를 이어가되 사용자의 첫 작업과 오류 해결은 계속 돕는다.
