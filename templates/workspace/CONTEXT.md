# 작업공간 안내

이곳은 에이전트와 함께 하는 일을 모으는 자리다. 현재 요청이 업무인지 개인인지 고른 뒤 해당 영역으로 이동한다.
사용자가 이미 작업을 지정했다면 다시 선택을 요구하지 않는다.

| 요청 | 다음 문서 |
|---|---|
| 회사·고객·직장 업무 | [업무/CONTEXT.md](업무/CONTEXT.md) |
| 생활·여행·공부 등 개인 일 | [개인/CONTEXT.md](개인/CONTEXT.md) |
| 공유 가능한 사용자 기억 | [.munteok/desk/memory/MEMORY.md](.munteok/desk/memory/MEMORY.md) |
| 현재 세션의 이어갈 일 | [.munteok/desk/agenda/current.md](.munteok/desk/agenda/current.md) |

새 작업의 계약은 [.munteok/workitem-template.md](.munteok/workitem-template.md),
완료 절차는 [.munteok/completion.md](.munteok/completion.md)에 있다.

프로젝트와 이슈의 목적·현재 상태·다음 행동은 해당 폴더의 `CONTEXT.md`가 정본이다.
여기에 세부 상태를 복사하지 않는다. 보관 자료는 요청을 받았을 때 검색한다.
