# 작업 이름

상태: 진행 중
소속: 업무/회사 또는 개인

## 목적과 완료 기준

무엇을 위해 하는 일인지, 어떤 결과를 확인하면 끝인지 적는다.

## 필요한 자료와 읽는 순서

필요한 입력·제약과 실제 파일의 상대 링크를 적는다. 다른 업무·개인 영역의 문서를 자동으로 읽지 않는다.

## 진행과 결과

현재 상태와 다음 행동을 적는다. 입력 원본은 `자료/`, 완성 파일은 `결과/`, 자신이 만든 중간 파일은 `임시/`에 둔다.
필요한 폴더만 만든다. 결과물과 편집 원본의 상대 링크를 남긴다.

## 완료와 기록 위치

완료 날짜, 남긴 결과, 다시 작업할 때 필요한 정보를 적는다.
보관 이동 전·후 절대경로와 에이전트 기록의 실제 위치를 적는다. 자격증명이나 토큰은 적지 않는다.
